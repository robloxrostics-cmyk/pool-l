# ChatPolls — AlphaGrief

Плагин голосований с GUI для Paper 1.21.11.

## Возможности
- GUI голосования и панель администратора.
- Режимы «Да/Нет», варианты из списка и викторина с правильным ответом.
- Один голос на игрока в рамках опроса.
- Сохранение активного опроса, голосов и истории в `plugins/ChatPolls/data.yml`.
- Автоматический опрос каждый час (интервал настраивается).
- 10 стандартных вопросов; список перемешивается и не повторяется до полного прохода.

## Сборка
Нужны JDK 21+ и Maven:
```bash
mvn clean package
```
Готовый JAR: `target/ChatPolls-1.0.0.jar`.

## Установка
1. Собери проект командой выше.
2. Перемести JAR в папку `plugins` сервера Paper 1.21.11.
3. Перезапусти сервер.
4. Игроки открывают меню: `/polls`.
5. Администраторы с `chatpolls.admin` открывают панель управления: `/polls`.

Настройки и 10 автоматических вопросов находятся в `plugins/ChatPolls/config.yml`.
